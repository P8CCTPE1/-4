# Домашняя работа 4
 
## Условие задачи
 
В кафе вай фай пароль обновляется каждый час на основе двух цифр (A и B). Новый пароль активен, если ровно одно из этих чисел четное. Запишите условие активности пароля.
 
## 1. Алгоритм и блок-схемы
 
###Алгоритм:
1. Начало
2. Объявить переменные:
 • **A** — первая цифра пароля.
 • **B** — вторая цифра пароля.
3. Составить условие при помощи операторов if и else.
4. Пароль активен, если ровно одно из чисел четное.
5. Конец. 
Условие активности пароля:
```c
((A % 2 == 0) && (B % 2 != 0)) || ((A % 2 != 0) && (B % 2 == 0))
 ```
## 2. Реализация программы
```c
#include <locale.h>
#include <stdio.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    int A;
    puts("Введите первую цифру (A):");
    scanf("%d", &A);

    int B;
    puts("Введите вторую цифру (B):");
    scanf("%d", &B);

    if (((A % 2 == 0) && (B % 2 != 0)) || ((A % 2 != 0) && (B % 2 == 0)))
    {
        puts("Пароль активен!");
    }
    else
    {
        puts("Пароль неактивен.");
    }

    return 0;
}
 ```
## 3. Результаты работы программы
